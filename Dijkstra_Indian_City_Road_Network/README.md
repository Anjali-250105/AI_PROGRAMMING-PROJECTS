# AI Programming Assignments

This repository contains implementations of Artificial Intelligence programming assignments using Python.

## Project 1: Dijkstra's Algorithm for Indian City Road Network

### Aim
To implement Dijkstra's algorithm for finding the shortest road-distance path between cities in India.

### Description
This project represents Indian cities as nodes and road distances between cities as weighted edges. Dijkstra's algorithm is implemented to find the shortest path from a selected source city to a selected destination city.

### Algorithm Used
- Dijkstra's Algorithm
- Weighted Graph
- Priority Queue

### Technologies Used
- Python
- Google Colab
- NetworkX
- Matplotlib

### Features
- Indian city road-distance network
- User can select source and destination cities
- Finds the shortest route
- Calculates total road distance
- Displays explored cities
- Visualizes the road network and shortest path

### Input
The user provides:
- Source city
- Destination city

### Output
The program displays:
- Shortest route
- Total distance in kilometres
- Cities explored during the search
- Graphical representation of the road network
- Highlighted shortest path

### Result
Dijkstra's algorithm successfully finds the shortest road-distance path between the selected Indian cities.
